# Security Policy

## Reporting a vulnerability

Please do not publish sensitive vulnerability details in a public issue.

For security reports, contact the repository maintainer privately through the contact method listed on the maintainer's GitHub profile. Include a clear description, affected version, reproduction steps, and potential impact. Do not include real credentials, tokens, or other secrets in a report.

## Scope

RepoLens is intended to inspect repository metadata and structure without modifying the target repository. Security reports involving unsafe file handling, unexpected code execution, secret exposure, dependency issues, or integrity problems are welcome.
